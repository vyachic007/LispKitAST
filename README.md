# LispKit AST

## О проекте

**LispKit AST** — консольное Java-приложение для разбора выражений языка LispKit и построения их абстрактного синтаксического дерева (AST).

Программа принимает LispKit-выражение, разбирает его структуру и представляет результат в виде узлов `ATOM` и `CONS`. После разбора пользователь может посмотреть логическое представление AST, полное CONS-дерево, содержимое ячеек памяти и восстановленное исходное выражение.

Проект демонстрирует принципы синтаксического разбора Lisp-подобных выражений и представления списков с помощью CONS-ячеек.

> Программа выполняет синтаксический разбор и построение AST. Она не вычисляет LispKit-выражения и не выполняет операции вроде `SUB`, `ADD`, `CDR` или `QUOTE`.

## Возможности

- Чтение LispKit-выражения из консоли.
- Разбор атомов и вложенных списков.
- Построение AST на основе ячеек `ATOM` и `CONS`.
- Представление списка через поля `HEAD` и `TAIL`.
- Отображение логического AST.
- Отображение полного CONS-дерева.
- Вывод ячеек памяти и связей между ними.
- Восстановление LispKit-выражения по построенному дереву.
- Обработка некорректного ввода и ошибок синтаксического разбора.

## Структура проекта

Основная логика разделена между классами.

### `Cell`

Класс `Cell` представляет отдельную ячейку памяти AST.

Ячейка может быть одного из двух типов:

- **ATOM** — хранит атом, например `SUB`, `7` или `NIL`.
- **CONS** — хранит ссылки на две части структуры: `HEAD` и `TAIL`.

Для CONS-ячейки:

- `HEAD` указывает на первый элемент списка или выражения.
- `TAIL` указывает на оставшуюся часть списка.

Таким образом, список строится как цепочка CONS-ячеек.

### `Ast`

Класс `Ast` отвечает за построение и обработку AST.

Его задачи:

- разбирать LispKit-выражение;
- создавать ячейки `ATOM` и `CONS`;
- связывать ячейки в дерево;
- хранить корень построенного AST;
- предоставлять представления дерева для вывода;
- восстанавливать выражение из AST.

### `LispKitConsole`

Класс `LispKitConsole` отвечает за консольное взаимодействие с пользователем.

Он организует ввод выражения и вывод результатов работы программы. Логика построения AST вынесена в отдельные классы, поэтому консольный класс не должен самостоятельно создавать и связывать ячейки дерева.

## Представление AST

В основе структуры лежат два вида ячеек:

| Тип | Назначение |
|---|---|
| `ATOM` | Представляет неделимый элемент выражения |
| `CONS` | Представляет пару ссылок `HEAD` и `TAIL` |

Например, выражение:

```lisp
(SUB 3 7)
```

представляется как список, состоящий из атомов `SUB`, `3` и `7`. Список формируется последовательностью CONS-ячеек, а завершение списка обозначается `NIL`.

Упрощённая схема:

```text
CONS
├── HEAD → ATOM(SUB)
└── TAIL → CONS
    ├── HEAD → ATOM(3)
    └── TAIL → CONS
        ├── HEAD → ATOM(7)
        └── TAIL → ATOM(NIL)
```

Это схематическое представление структуры: конкретный формат вывода дерева зависит от реализации методов отображения AST.

## Как работает разбор

В общем виде обработка выражения выполняется следующим образом:

1. Пользователь вводит LispKit-выражение.
2. Входная строка разбивается на элементы, необходимые для синтаксического разбора.
3. Парсер определяет, где находятся атомы и вложенные списки.
4. Для атомов создаются ячейки `ATOM`.
5. Для списков создаются CONS-ячейки с полями `HEAD` и `TAIL`.
6. Ячейки связываются в AST.
7. Построенное дерево выводится в выбранных представлениях.
8. При необходимости исходное выражение восстанавливается из структуры AST.

Вложенные списки разбираются рекурсивно, поэтому выражения могут содержать другие выражения в качестве элементов.

## Примеры выражений

### Простое выражение

```lisp
(SUB 3 7)
```

В выражении присутствуют оператор `SUB` и два атомарных аргумента. Программа строит структуру AST, но не вычисляет результат вычитания.

### Вложенное выражение

```lisp
(SUB (ADD 2 4) 7)
```

В этом примере один из элементов списка сам является списком. Парсер должен сначала построить AST для вложенного выражения `(ADD 2 4)`, а затем включить его в структуру внешнего выражения.

Программа сохраняет синтаксическую структуру и не вычисляет ни `ADD`, ни `SUB`.

## Обработка ошибок

При разборе входной строки могут возникать ошибки, связанные с некорректным синтаксисом, например:

- незакрытая круглая скобка;
- лишняя закрывающая скобка;
- пустой или некорректный ввод;
- неожиданная последовательность элементов.

Некорректное выражение не должно приводить к построению корректного AST. Сообщение об ошибке позволяет пользователю понять, что введённая структура не может быть разобрана.

Точный текст сообщений и перечень проверок определяются реализацией парсера.

## Запуск

Для запуска необходима установленная Java.

Если проект содержит файл сборки (например, Maven или Gradle), используйте предусмотренную им команду запуска. Если проект представлен обычными Java-файлами, его можно скомпилировать и запустить средствами JDK или IDE.

Основной класс приложения:

```text
LispKitConsole
```

Пакет проекта:

```text
by.slava_borisov.lispkitast
```

В IntelliJ IDEA или другой Java IDE:

1. Откройте проект.
2. Убедитесь, что выбран подходящий JDK.
3. Найдите класс `LispKitConsole`.
4. Запустите его метод `main`.
5. Введите LispKit-выражение в консоли.

Точные команды компиляции и запуска зависят от фактической структуры проекта и используемой системы сборки.

## Ограничения

- Программа предназначена для синтаксического разбора, а не для вычисления выражений.
- Операторы LispKit рассматриваются как элементы AST.
- Поддерживаемый синтаксис определяется текущей реализацией парсера.
- Программа не является полноценной LispKit-средой исполнения.

## Назначение проекта

Проект предназначен для изучения:

- синтаксического разбора Lisp-подобных языков;
- рекурсивной обработки вложенных выражений;
- абстрактных синтаксических деревьев;
- представления списков с помощью CONS-ячеек;
- разделения ответственности между классами Java.

Он показывает, как строковое выражение преобразуется в структурированное представление, пригодное для анализа и последующего восстановления исходной записи.
